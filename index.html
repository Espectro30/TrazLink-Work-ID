01 // INTRODUCCIÓN & PLANTEAMIENTO DEL PROBLEMA ÁREA: INDUSTRIA Y PRODUCTIVIDAD
¿Por qué es necesario este producto?

La Problemática del Control Laboral en la Industria

En pequeñas y medianas empresas, talleres mecánicos, almacenes logísticos y fábricas con turnos rotativos, la gestión de asistencia y puntualidad adolece de serias deficiencias operativas:

  • ✕ Vulnerabilidad de registros tradicionales: Las listas en papel o libros manuales de firmas sufren de falsificación y suplantación de identidad.
  • ✕ Barrera económica de terminales propietarios: Soluciones comerciales de marcas cerradas (ZKTeco, Hikvision) tienen costos de $350-$600 USD y cobran suscripciones en la nube.
  • ✕ Fallas por pérdida de red: Relojes biométricos comerciales colapsan o pierden marcas cuando el enlace WiFi o la energía eléctrica se interrumpe.
¿Qué necesidad resuelve?

Automatización Forense de Turnos y Pre-Nómina

TrazLink™ Work-ID resuelve integralmente la trazabilidad del tiempo laboral implementando un terminal de acceso montado en pared:

Marcaje Ultrarrápido (< 200 ms) Identificación con tarjetas inteligentes RFID de 13.56 MHz (Mifare Classic 1K).
Inmutabilidad Temporal (Hardware RTC) Oscilador TCXO con batería LIR2032 recargable que previene alteraciones de horario y fraude salarial.
Cálculo Salarial en el Borde (Edge Computing) Discrimina horas ordinarias, recargos nocturnos (+30%), horas extra diurnas (+50%) y retardos en tiempo real.

03 // DESARROLLO TÉCNICO: DIAGRAMA DE FLUJO LÓGICA DE CONTROL DEL MICROCONTROLADOR

Flujo Secuencial de Detección, Validación y Cómputo

Algoritmo determinista ejecutado entre los dos núcleos del ESP32-S3.

1

REPOSO & RTC

Muestreo continuo del RTC DS3231 por I2C y refresco del reloj TFT vía SPI DMA.

2

LECTURA RFID

Interrupción en MFRC522 (Bus SPI 2). Se captura el UID del carnet en menos de 50ms.

3

VALIDACIÓN NVS

Verificación del UID contra la tabla local indexada en memoria flash interna.

4

CÓMPUTO SALARIAL

Cálculo de tolerancia, retardo, horas ordinarias y recargos nocturnos o extras.

5

FEEDBACK & BUFFER

TFT muestra confirmación, buzzer emite chime y el registro se guarda en LittleFS.

Tiempo total de ciclo de marcaje: < 180 milisegundos (Arquitectura reactiva y no bloqueante)

06 // DESARROLLO TÉCNICO: CÓDIGO & FREERTOS MULTITAREA SIMÉTRICA (SMP)

Estructura Modular del Firmware C++

El código aprovecha los dos núcleos del ESP32-S3 mediante el sistema operativo en tiempo real FreeRTOS:

CORE 0: PROTOCOLOS & HARDWARE E/S Polling del MFRC522, lectura I2C del DS3231 y buffer en flash LittleFS.
CORE 1: MOTOR GRÁFICO & MÁQUINA DE ESTADOS Renderizado de alta velocidad por DMA en SPI 1 y procesamiento táctil.
// Fragmento de Configuración FreeRTOS (main.cpp) 
xTaskCreatePinnedToCore(
    taskRFID_RTC,    // Función de E/S
    "TaskIO",        // Nombre
    4096,            // Stack (bytes)
    NULL,            // Parámetro
    2,               // Prioridad Alta
    NULL,            // Handle
    0                // Asignado a CORE 0
);

xTaskCreatePinnedToCore(
    taskGUI_TFT,     // Función HMI
    "TaskTFT",       // Nombre
    8192,            // Stack (bytes)
    NULL,            // Parámetro
    1,               // Prioridad Media
    NULL,            // Handle
    1                // Asignado a CORE 1
);
